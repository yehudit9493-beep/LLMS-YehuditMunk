# DevChat

## הפעלה

יש להגדיר את מפתח SafeAI במשתנה סביבה, ולא לשמור אותו בקובצי הקוד. ב-PowerShell:

```powershell
$env:SAFEAI_API_KEY = "המפתח החדש שלך"
python -m uvicorn server:app --reload
```

בחלון PowerShell נוסף, הפעלת הקליינט:

```powershell
npm --prefix my-app run dev
```

## זיכרון שיחה

הקליינט שומר מזהה שיחה בדפדפן ושולח לשרת רק את ההודעה החדשה. השרת שומר את התורות
של המשתמש והמודל בזיכרון לפי מזהה השיחה, ומוסיף אותם להקשר של כל בקשה חדשה.
כפתור הניקוי מוחק את ההיסטוריה מהשרת ומייצר מזהה שיחה חדש.

הזיכרון נשמר בזיכרון התהליך בלבד: הפעלה מחדש של השרת או שימוש בכמה תהליכי שרת
ללא אחסון משותף יאפסו או יפצלו את ההיסטוריה.
